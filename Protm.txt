# 2. AUTHORIZATION / SECURITY BOUNDARY

Chỉ nghiên cứu:

* public website;
* account/session hiện tại mà người dùng đã cho phép;
* route browser hiện tại được phép truy cập;
* API request phát sinh trong flow bình thường;
* response mà browser thực sự nhận được;
* asset public;
* JS/CSS/public bundles browser tải về.

KHÔNG:

* bypass authentication;
* bypass authorization;
* brute force route;
* khai thác vulnerability;
* đoán hidden admin endpoint;
* tìm database password;
* lấy `.env` remote;
* lấy server secret;
* export cookie/token để sử dụng ngoài scope;
* cố truy cập dữ liệu người dùng khác;
* gọi API trái với flow bình thường của website;
* dò source code backend private từ server.

Nếu chỉ có website chạy:

```text
KHÔNG được tuyên bố đã lấy backend source gốc.
```

Thay vào đó:

```text
observable behavior
+
observable API contract
+
existing PROJECT_ROOT architecture
=
new equivalent backend implementation
```
